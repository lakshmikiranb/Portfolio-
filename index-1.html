Troubleshooting case studies

Illustrative scenarios only. These are templates showing my troubleshooting approach, not real incidents or achievements.

Illustrative

Windows client has no network access

Problem: A domain-joined PC cannot reach network resources.

Symptoms: No internet, intranet pages fail, mapped drives missing.

Checklist: cable/Wi-Fi, IP configuration, gateway, DNS resolution, service state.

ipconfig /all        # IP, gateway, DNS, DHCP lease
ping <gateway>       # local network reachability
nslookup <server>    # is DNS resolving?
Get-Service Dnscache # DNS client service state

Possible root cause: e.g. a 169.254.x.x address from a failed DHCP lease.

Resolution: ipconfig /release then /renew; check the DHCP scope/server if it persists.

Prevention: monitor DHCP scope usage; document the fix in the KB.

Illustrative

Group Policy not applying to a user

Problem: A mapped drive or setting from a GPO is missing.

Symptoms: Login script did not run, expected drive absent.

Checklist: OU placement, security group membership, GPO link and scope, DNS to the domain controller, time sync.

gpupdate /force   # refresh policy now
gpresult /r       # which GPOs applied/denied
nslookup <domain> # can the client find the DC?

Possible root cause: e.g. user account in the wrong OU or missing a required group.

Resolution: correct the OU or group (within assigned permissions), then refresh policy and re-verify with gpresult.

Prevention: standard OU structure and documented onboarding checklist.
